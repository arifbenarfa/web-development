FROM BRIEF TO BROWSER

A little plan
goes a long way.

I began by choosing a simple subject and deciding what a visitor should notice first. A clear heading gives the page a starting point; short sections make the story easy to follow.

Then I wrote the structure in HTML and moved the visual choices into a separate CSS file. Keeping content and style in their own files makes each part easier to read and adjust.

MY WORKING NOTES

Three steps that helped.

01 / PLAN

Give the page a purpose

Pick one topic, write a useful heading, and group related ideas before adding decoration.

02 / BUILD

Keep structure clear

Use HTML for headings, paragraphs, navigation, and the photo. Link the page to an external style.css file.

03 / CHECK

Review the details

Describe the photo with alt text, validate the HTML, and check that the published page and image both load.
